하나의 논쟁적 질문을 찬성(PRO)/반대(CON) 양측으로 토론시키고 중립 심판(JUDGE)이 결론을
내리는 **멀티에이전트 토론**을 진행한다. 각 역할은 `.claude/agents/` 에 정의된 **독립
서브에이전트**이며(모델·페르소나가 각 파일에 고정되어 서로 격리됨), Agent 도구로 순차
호출한다. 별도 API 키·요금 없이 현재 세션에서 동작한다.

## 주제

$ARGUMENTS

주제가 비어 있으면, 찬반이 명확히 갈리는 **단일 명제(yes/no 형태)** 주제를 사용자에게 먼저
물어라. "~ 전망은?", "어느 쪽이 유리한가?" 같은 비-찬반/다지선다형이면 찬반형으로 다듬도록
제안하라.

## 진행 순서 — 서브에이전트 5회 순차 호출

각 단계는 Agent 도구 1회 호출이다. `subagent_type` 에 아래 에이전트 이름을 지정하고,
**앞 단계의 결과 텍스트를 다음 호출 프롬프트에 그대로 넣어** 전달한다.

| 단계 | subagent_type | 프롬프트에 넣어 전달할 입력 |
|------|---------------|------------------------------|
| 1 | `debate-pro`   | 주제 |
| 2 | `debate-con`   | 주제 + 1단계(PRO 입론) |
| 3 | `debate-pro`   | 주제 + 2단계(CON 반박) + 1단계(자신의 입론) |
| 4 | `debate-con`   | 주제 + 3단계(PRO 재반박) + 2단계(자신의 반박) |
| 5 | `debate-judge` | 주제 + 1~4단계 전체 |

> 모델·페르소나는 각 에이전트 파일에 고정되어 있다(`debate-pro`/`debate-con` = Sonnet,
> `debate-judge` = Opus). 호출 시 `model` 을 따로 지정하지 마라.

## 최종 출력

5개 마크다운 섹션으로 정리해 사용자에게 보여줘라:
`## 찬성 입론 (PRO)` / `## 반대 반박 (CON)` / `## 찬성 재반박 (PRO)` / `## 반대 재반박 (CON)` /
`## 종합 판단 (JUDGE)`.

## 저장 및 제공 (토론 종료 후 자동 실행)

위 5개 섹션 정리를 사용자에게 보여준 뒤, 다음을 자동으로 수행한다.

1. **마크다운 파일 저장** — `debates/` 폴더에 결과를 저장한다.
   - 파일명: **주제를 요약한 ASCII 슬러그**(소문자, 단어는 하이픈으로 구분)에 날짜를 접두로 붙인다 →
     `debates/<YYYY-MM-DD>-<topic-slug>.md`. 날짜는 환경의 현재 날짜를 사용한다.
   - 같은 이름이 이미 있으면 끝에 `-2`, `-3` … 을 붙여 덮어쓰지 않는다.
   - **문서 구성:**
     - (a) 맨 위: 제목(질문) · 일자 · 구성(PRO/CON = Sonnet, JUDGE = Opus) · 참고자료(있으면) · 한 줄 요약.
     - (b) **`## 들어가며 (배경과 핵심 용어)`** 섹션 — 이 토론을 처음 보는 사람도 이해할 수 있도록:
       (i) 주제의 배경과 왜 쟁점이 되는지를 2~4문장으로 설명하고,
       (ii) 본문에 등장하는 핵심 전문용어를 "**용어** — 풀이" 형태의 짧은 용어집으로 정리한다.
       전문용어 자체(예: FEOC, MACR, 45X)는 키워드이므로 **그대로 쓰되**, 그 의미와 맥락을 한 줄로 풀어준다.
     - (c) 이어서 5개 섹션 전체(찬성 입론 / 반대 반박 / 찬성 재반박 / 반대 재반박 / 종합 판단)와
       각 섹션의 주요 출처.
   - **서술 방식:** 처음 보는 사람도 따라올 수 있도록, 함축적 약어·화살표(`→`)·전보식 단편 대신
     **완결된 문장으로 풀어** 쓴다. 단, 전문용어 키워드는 풀어 쓰지 말고 그대로 사용한다(맥락만 설명).
2. **GitHub 저장** — 그 파일을 git add → commit → **현재 브랜치**로 push 한다.
   커밋 메시지 예: `Add debate: <주제 요약>`. (network 오류 시 2s·4s·8s·16s 백오프로 최대 4회 재시도.)
3. **파일 제공** — SendUserFile 로 저장한 `.md` 파일을 사용자에게 전달한다.
