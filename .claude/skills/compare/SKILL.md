# 파이프라인 비교

## 절차

1. 모든 `00X-*` 폴더의 `00-screen.md`(있으면 `01-ic-memo.md`, `04-decision.md`도)를 읽는다.
2. 각 매물의 상태·점수·핵심 지표를 추출한다.
3. `pipeline.md`를 갱신한다:
   - 활성 매물을 **점수 순**으로 정렬
   - KILL된 매물은 하단 별도 섹션에 사유와 함께 보관 (삭제하지 말 것 — 시장 감각의 기록이다)
4. 사용자에게 **상위 3건과 그 차이**를 요약한다.

## 단순 갱신 이상이 필요한 경우

매물이 3건 이상 쌓이면 다음을 함께 짚는다:

- **배수 분포** — 시장 배수 감각이 잡히고 있나? 지금 보는 가격들이 싼 편인가 비싼 편인가
- **반복되는 KILL 사유** — 같은 이유로 계속 탈락한다면 소싱 기준(어떤 매물을 보는가) 자체를 조정해야 한다
- **점수는 높은데 진행이 막힌 매물** — 무엇이 병목인가

## 이 파일의 목적

pipeline.md는 진행 상황판이자 **시장 배수 감각의 축적 기록**이다.
첫 딜 전에 5~10건을 스크리닝하라고 권하는 이유가 이것이다 — 비교군 없이는 "싸다/비싸다"를 판단할 수 없다.
