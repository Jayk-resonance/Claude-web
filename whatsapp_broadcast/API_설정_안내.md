# WhatsApp Cloud API 발송 설정 안내 (비개발자용, 단계별)

> ℹ️ **참고**: 순수 Meta 직접 방식으로는 비개발자가 **Coexistence(기존 번호 유지 + 앱에서
> 답장 관리)**를 켜기 어려워, 최종적으로 **BSP + Coexistence 방식**으로 진행하기로 했습니다.
> → **`BSP_Coexistence_안내.md`** 를 보세요. 아래 내용은 순수 Meta 직접 방식의 **참고용**입니다.

교인들에게 **동일 메세지(10개 틀)를 API로 발송**하기 위한 전체 설정 가이드입니다.
발송은 같은 폴더의 `send_whatsapp.py` 스크립트로 합니다.

- **기존 Business 앱 번호를 그대로 사용**하고 **Coexistence(코이그지스턴스)** 로
  같은 번호에 API를 연결합니다. → **발송은 API로 전체에게**, **답장·대화 관리는 지금 쓰던
  WhatsApp Business 앱에서** 그대로. (앱 대화·연락처·컴퓨터 연동 유지)
- 개인화 없음(모두 동일 문구) → 템플릿에 변수를 넣지 않습니다.
- 비용: API로 보낸 메세지만 통당 과금(예: 콜롬비아 마케팅 ≈ $0.02). 앱에서 하는 답장은 무료.

전체 흐름:
**1)Meta 계정 → 2)앱 만들기 → 3)기존 번호 Coexistence 연결 → 4)토큰 발급 →
5)템플릿 10개 승인 → 6)발송 (+답장은 앱에서)**

> 💡 각 단계에서 화면 메뉴 이름은 Meta가 수시로 바꿉니다. 정확한 명칭이 조금 달라도
> "WhatsApp / 전화번호 / 템플릿 / 토큰" 키워드로 찾으면 됩니다.

---

## 1단계. Meta 비즈니스 계정 준비

1. **페이스북 개인 계정**으로 로그인(없으면 생성). 관리자 로그인용일 뿐입니다.
   - ✅ 이 로그인 계정은 **WhatsApp 발송 번호와 무관**합니다. 목사님 개인 이메일/번호
     아무거나 쓰면 되고, WhatsApp 번호와 같을 필요 없습니다. (신규 가입 시 **이메일로**
     가입하면 WhatsApp 번호와 얽히지 않아 깔끔합니다.) 실제 교회 번호는 3단계에서 붙습니다.
2. **Meta Business Manager** 접속 → https://business.facebook.com → **비즈니스 만들기**.
   - 비즈니스 이름(교회 이름), 본인 이름, 이메일 입력.
3. (나중에 필요) **비즈니스 인증**: 초기엔 없어도 시작 가능. 발송 한도를 크게 늘릴 때
   교회 서류로 인증합니다. 지금은 건너뜁니다.

---

## 2단계. 개발자 앱 만들기 (WhatsApp 제품 추가)

1. **Meta for Developers** 접속 → https://developers.facebook.com → 우측 상단
   **내 앱 → 앱 만들기**.
2. 앱 유형은 **비즈니스(Business)** 선택 → 앱 이름(예: `church-broadcast`) 입력,
   1단계의 비즈니스 계정 연결.
3. 앱 대시보드에서 **WhatsApp** 제품을 찾아 **설정(Set up)** 클릭.
4. 화면에 **테스트용 번호**와 예시가 나옵니다. 여기서 **본인 폰(개인 WhatsApp)을
   테스트 수신자로 추가**해 "hello_world" 샘플이 오는지 먼저 확인하면 좋습니다.

이 화면(WhatsApp → API 설정)에서 아래 두 값을 확인할 수 있습니다:
- **전화번호 ID (Phone number ID)** — `.env` 의 `WHATSAPP_PHONE_NUMBER_ID`
- **임시 접근 토큰 (24시간)** — `.env` 의 `WHATSAPP_TOKEN` (테스트용)

---

## 3단계. 기존 번호를 Coexistence로 API에 연결

> **Coexistence(코이그지스턴스)** = 같은 번호를 **WhatsApp Business 앱 + Cloud API**에
> 동시에 쓰는 공식 기능(2025년~). 기존 대화·연락처가 앱에 그대로 남고, 답장도 앱으로 옵니다.

1. WhatsApp → **API 설정 / 전화번호** 화면에서 **전화번호 추가** 를 누릅니다.
2. **"이미 WhatsApp Business 앱에서 쓰는 번호"** 를 연결하는 옵션(Coexistence 온보딩)을
   선택합니다. → 화면에 **QR 코드**가 뜹니다.
3. **폰의 WhatsApp Business 앱**에서 QR을 스캔합니다
   (앱 → 설정 → **연결된 기기/기기 연결** 또는 화면에 안내되는 경로).
   - 스캔 시 **기존 대화 기록 공유 여부**를 물어보면 원하는 대로 선택.
4. 연결되면 그 번호의 **전화번호 ID(Phone number ID)** 를 `.env` 의
   `WHATSAPP_PHONE_NUMBER_ID` 에 넣습니다.

> ⚠️ 이 단계가 이 과정 중 가장 낯선 부분입니다. 앱 대시보드에서 Coexistence(기존 앱
> 번호 연결) 옵션이 안 보이면, 무코드 대행 플랫폼(360dialog 등)이 이 QR 연결을 클릭
> 몇 번으로 해줍니다(월 요금). 막히면 캡처를 보내주세요 — 같이 뚫겠습니다.

## 4단계. 접근 토큰 발급 (영구용)

임시 토큰은 24시간 뒤 만료됩니다. 실제 운영은 **영구 토큰**을 씁니다.

1. **Business Manager → 설정 → 사용자 → 시스템 사용자** → **시스템 사용자 추가**
   (역할: 관리자).
2. 그 시스템 사용자에 **본인 앱과 WhatsApp 계정 자산 할당**(권한: 관리).
3. **토큰 생성** → 앱 선택 → 권한 **`whatsapp_business_messaging`,
   `whatsapp_business_management`** 체크 → 만료 **없음(Never)** → 생성.
4. 나온 긴 토큰을 **한 번만 보이므로 즉시 복사** → `.env` 의 `WHATSAPP_TOKEN` 에 붙여넣기.

> `.env` 파일은 이 폴더의 `.env.example` 을 복사해 만들고, **절대 외부 공유·커밋 금지**
> (`.gitignore` 로 보호됨).

## 5단계. 메세지 템플릿 10개 등록·승인

API로 먼저 말을 거는 메세지는 **반드시 사전 승인된 템플릿**이어야 합니다.
목사님의 **10개 틀**을 각각 템플릿으로 등록합니다.

1. **WhatsApp Manager → 템플릿 → 템플릿 만들기**.
2. **카테고리**: 목회 안내·초청은 보통 **마케팅(Marketing)**.
3. **이름**: 영문 소문자·숫자·밑줄만 (예: `sunday_service`, `weekly_word_01`).
   → 이 이름을 스크립트 `--template` 에 씁니다.
4. **언어**: 교인들에게 맞는 언어(예: 스페인어 `es`, 한국어 `ko`). → `--lang` 값.
5. **본문**: 10개 틀 문구를 붙여넣기. **변수(예: {{1}})는 넣지 않습니다**(모두 동일 문구).
6. **제출** → 심사(보통 몇 분~하루). **승인(Approved)** 되면 발송 가능.

10개를 모두 이렇게 등록하면, 발송 때 이름만 바꿔 골라 쓰면 됩니다.

## 6단계. 발송하기

1. **받는 사람 명단 준비**: 이 폴더의 `recipients.example.csv` 를 참고해
   **`recipients.csv`** 를 만듭니다. 컬럼은 `name,phone`, 전화번호는 **국제형식(숫자만)**.
   - 콜롬비아 예: `573001234567` (57 + 번호), 한국 예: `821012345678` (82 + 앞 0 뺀 번호)
2. **`.env` 채우기**: `.env.example` 복사 → `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_TOKEN` 입력.
3. **미리보기**(발송 안 함):
   ```
   python send_whatsapp.py --template sunday_service --lang es --dry-run
   ```
4. **소수 테스트**(예: 본인 포함 2명만 담은 csv 또는 `--limit 2`):
   ```
   python send_whatsapp.py --template sunday_service --lang es --limit 2
   ```
5. **전체 발송**:
   ```
   python send_whatsapp.py --template sunday_service --lang es
   ```

- 발송 결과는 `sent.log` 에 기록되고, **재실행하면 이미 성공한 사람은 자동으로 건너뜁니다**
  (중간에 끊겨도 이어서 발송).
- `--delay 1.0` 으로 발송 간격(초)을 조절할 수 있습니다(기본 1초).

> ⚠️ **첫 며칠 한도**: 새 번호는 초기 발송 한도(예: 하루 250명)가 있을 수 있습니다.
> 품질이 좋으면 자동으로 1,000 → 10,000명으로 올라갑니다. 166~200명은 보통 문제 없음.
> 수신 거부(차단·신고)가 많으면 품질 등급이 떨어지니, 원하는 교인에게만 보내세요.

## 답장·대화 관리 (Coexistence의 핵심 장점)

- API로 보낸 안내에 교인이 **답장하면, 지금 쓰시던 WhatsApp Business 앱으로 옵니다.**
  거기서 평소처럼 읽고 답장하면 됩니다(컴퓨터 연동·WhatsApp Web 그대로).
- API로 보낸 메세지도 **앱·데스크톱(WhatsApp Web)의 해당 교인 대화창에 그대로 보입니다.**
  → 발송 후 대화창을 열어 **"제대로 나갔는지 + 체크표시(✓✓ 전달·파랑 읽음) + 답장"** 을
  한눈에 확인할 수 있습니다(따로 로그 뒤질 필요 없음).
- 즉 **보내기는 API(스크립트)로 전체에게, 받기·답장은 앱에서** — 익숙한 방식 유지.
- 앱에서 목사님이 직접 보내는 답장·대화는 **무료**(과금은 API로 보낸 안내 메세지만).

> 참고: Coexistence 연결 전의 **과거 대화 기록은 API쪽으로 옮겨지지 않지만** 앱엔 그대로
> 남습니다. 그룹 대화는 앱에서만 보입니다.

## 명단 관리 — 매달 반복 사용 팁

API에는 앱 같은 **주소록이 없습니다**(번호로 바로 발송). 대신 받는 사람 목록을
`recipients.csv` 로 관리합니다. **처음부터 다시 저장하는 게 아니라**, 이미 폰·구글
연락처에 있는 걸 **한 번 내보내서** 재사용합니다.

1. **마스터 명단**은 지금처럼 **구글 연락처 / 구글 스프레드시트**로 관리(컴퓨터 연동 유지).
2. 발송 전 거기서 **이름·전화번호만 뽑아 `recipients.csv`** 로 내보내기.
   - 구글 연락처: contacts.google.com → **내보내기 → Google CSV** → 이름·전화 열만 남김.
3. 전화번호는 **국제형식(숫자만)**: 콜롬비아 `57…`, 한국 `82…`(앞 0 제외).
4. **매달**은 새 교인 줄만 추가 → 다시 내보내기 → 발송. 200명을 매번 재입력하지 않습니다.

> 기존 WhatsApp Business 앱·폰 연락처 관리는 그대로 유지됩니다. CSV는 발송용 사본일 뿐입니다.

## 참고 — 비용 요약

- 통당 과금(글자 수 무관). 콜롬비아 마케팅 ≈ 통당 $0.02.
- 200명 × 1통 ≈ $4 / 200명 × 10통 ≈ $40. (받는 분 국가·카테고리에 따라 달라짐)
- 월 구독료는 없음(Meta 직접 방식). 통당 요금만 청구.
