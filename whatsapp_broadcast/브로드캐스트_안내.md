# WhatsApp 브로드캐스트로 교인 166명에게 동일 메세지 보내기 (Android 안내)

전도사님이 교인 약 **166명**에게 **동일한 메세지**를 각자 **개별 1:1**로 보내기 위한
단계별 안내입니다. WhatsApp의 **브로드캐스트 목록(Broadcast list)** 기능을 사용합니다.
무료이고, 코딩이 필요 없으며, 계정 차단 위험도 낮습니다.

> **브로드캐스트 목록이란? (단체방 아님!)**
> 한 목록에 여러 명(최대 256명)을 담아두고 메세지를 보내면, **각 교인에게 개별 1:1
> 대화로 따로따로** 도착합니다. = "166명에게 각각 개인 문자 보낸 것과 똑같은 결과"인데
> 목사님은 한 번만 입력·전송하면 됩니다.
>
> - 교인 화면: 그냥 **목사님과의 1:1 대화창**에 도착. 다른 수신자·서로의 대화 안 보임.
>   답장도 목사님에게만 1:1로 옴.
> - **"새 그룹/커뮤니티"와 다릅니다** — 그건 서로 다 보이는 단체 채팅방입니다.
> - 목사님 폰의 대화 목록에 생기는 **📢 목록은 "보내기용 목록"일 뿐**, 교인들에게는
>   **안 보입니다**(단체방이 생기는 게 아님).

---

## ⚠️ 가장 중요한 제약 — 먼저 읽어주세요

브로드캐스트 메세지는 **받는 사람이 목사님 번호를 자기 폰 연락처에 저장해둔 경우에만**
도착합니다. 저장하지 않은 교인에게는 **조용히 전달되지 않습니다**(오류 표시도 없음).

- 그래서 **0~1단계**에서 "번호 저장 요청"을 먼저 하고,
- **5단계**에서 실제로 누가 못 받았는지 확인해 그 소수만 따로 챙깁니다.

## 0. 준비 — WhatsApp Business 앱 (권장)

일반 WhatsApp로도 브로드캐스트가 되지만, **WhatsApp Business 앱**을 권장합니다(무료).
- **빠른 답장(Quick reply)**: 자주 쓰는 문구를 단축어로 저장해 즉시 입력 → 10개 틀에 유용.
- **라벨(Label)**: 교인들을 '교인' 등으로 분류해 관리하기 편함.

전환 방법:
1. Play 스토어에서 **WhatsApp Business** 설치.
2. 처음 실행 시 **기존 WhatsApp 계정·대화·번호를 그대로 가져오기** 옵션 선택.
   (같은 번호를 그대로 쓰며, 기존 1:1 대화가 유지됩니다.)

> 전환이 부담되면 일반 WhatsApp 그대로도 됩니다. 이 경우 아래 "빠른 답장" 대신
> **삼성 노트**나 **나에게 보내기**에 10개 틀을 저장해두고 복사해 쓰세요(3단계 참고).

## 2. 브로드캐스트 목록 만들기 (Android / 삼성)

> ⚠️ **메뉴 이름 주의**: 한국어 WhatsApp은 "브로드캐스트"를 **"새 단체 메시지"**로
> 표기합니다. **"새 그룹"·"커뮤니티"와 다릅니다** — 그건 단체 채팅방이라 서로 다 보이고,
> **"단체 메시지"**가 각자에게 1:1로 가는 브로드캐스트입니다.

1. WhatsApp(또는 Business) 앱을 엽니다.
2. **대화(채팅)** 화면에서 오른쪽 위 **⋮ (더보기)** 를 누릅니다.
3. **새 단체 메시지** 를 선택합니다. (영어 UI에서는 *New broadcast*)
4. 목록에 넣을 **교인들을 하나씩 탭해서 선택**합니다(최대 256명 → 166명은 1개 목록으로 충분).
   - 연락처에 저장된 사람만 선택 목록에 나타납니다.
5. 오른쪽 아래 초록색 **체크(✔)** 를 눌러 목록을 만듭니다.
6. 대화 목록에 **📢 표시된 "보내기용 목록"** 이 생겨 계속 재사용됩니다.
   (이건 목사님 폰에만 보이는 목록이고, 교인들에게는 단체방이 생기지 않습니다.)

> **팁**: 목록 이름은 상단을 눌러 "교인 전체" 등으로 바꿀 수 있고, 나중에 인원
> 추가/삭제도 가능합니다(방 상단 제목 → 정보 → 수신자 편집).
>
> **Business 앱 라벨 팁**: 각 교인 대화에 '교인' 라벨을 달아두면, 나중에 목록을
> 다시 만들거나 대상을 관리할 때 찾기 쉽습니다.

## 2-1. 계정 차단(ban) 걱정 — 목사님은 저위험

"브로드캐스트 쓰면 차단된다"는 후기가 있지만, **기능 자체가 차단 사유는 아닙니다.**
WhatsApp이 실제로 계정을 막는 원인은 따로 있습니다:

- **가장 큰 원인**: 받는 사람들의 **스팸 신고**가 여러 건 쌓일 때
- 모르는 번호에 **홍보성 메세지를 반복 발송**할 때
- **비공식 대량발송 앱**(whatsapp-web.js 등) 사용 → 자동 발송 패턴 감지 시 **영구 차단**

목사님의 경우는 ①받는 분들이 **목사님을 알고 번호를 저장한 교인**(동의된 수신)
②내용이 **광고가 아니라 목양·안내** ③**공식 기능**만 사용 → **스팸 신고가 날 이유가
거의 없어 저위험**입니다. 아래 수칙만 지키면 됩니다.

- 번호를 저장하고 메세지를 **원하는 교인**에게만 보내기
- **너무 자주 보내지 않기** (매일 도배 금지)
- 그만 받고 싶다는 분은 **목록에서 제외**
- **비공식 대량발송 앱은 절대 사용하지 않기**

## 2-2. 166명 선택이 번거로울 때 — 더 편하게

**먼저 안심하세요: 166명 선택은 목록 만들 때 딱 한 번뿐입니다.** 한 번 만든 단체
메시지 방(📢)은 영구히 남아 재사용되므로, 이후 발송은 *방 열기 → 붙여넣기 → 전송*
3번 터치로 끝납니다. 매번 다시 고르지 않습니다.

그 1회 선택을 빠르게 하는 법:

1. **선택 화면 상단 검색창** 활용 — 이름을 쳐서 나오는 사람만 체크. (전체 선택 버튼은 없음)
2. **이름에 공통 키워드 넣기** — 교인 연락처 이름에 공통 단어(예: `성도`, `교회`, `✝`)를
   넣어두면, 선택 화면 검색창에 그 단어만 쳐도 교인들만 걸러져 훨씬 빠릅니다.

**⭐ 가장 편한 방법 — WhatsApp Business "라벨"로 한꺼번에 보내기:**

한 명씩 체크하는 게 싫다면 이 경로를 쓰세요. **라벨에 넣어둔 전원이 자동 선택**됩니다.

1. 각 교인 대화에 미리 **`교인` 라벨**을 달아둡니다(대화방 → ⋮ → 채팅에 라벨 지정).
2. 보낼 때: **⋮ (더보기) → 라벨 → `교인` 라벨 선택(열기)**
3. 라벨 화면에서 다시 **⋮ (더보기) → 고객에게 메시지 보내기**
4. → **라벨 달린 전원이 자동 포함** → 초록 **체크(✔)**
5. 문구 입력 → 전송 → 전원에게 **개별 1:1** 발송.

> ⚠️ **주의**: "새 단체 메시지"에서 라벨로 *검색*하면 여전히 한 명씩 체크해야 합니다.
> 위처럼 **라벨 메뉴로 먼저 들어가** "고객에게 메시지 보내기"를 눌러야 전원이 한 번에
> 선택됩니다. (라벨은 WhatsApp **Business** 앱 기능)
>
> 참고: "새 단체 메시지" 검색으로 체크할 때, 검색어가 지워져도 **체크한 사람은 화면
> 위쪽에 그대로 담겨 있습니다**(진행 초기화 아님).

> 명단(엑셀)을 올려 선택 없이 발송하는 완전 자동은 유료 Business API 영역 → 지금은 과함.

## 3. 10개 틀을 복사하기 쉽게 보관

발송할 때 문구를 빠르게 복사하려면, 아래 중 한 곳에 10개 틀을 저장해 둡니다.
(문구 정리는 같은 폴더의 **`틀_모음.md`** 참고)

- **방법 A — 삼성 노트 / Google Keep**: 10개 틀 전문을 저장. 길이 제한 없이 안정적.
  발송 시 필요한 틀을 길게 눌러 복사 → WhatsApp에 붙여넣기.
- **방법 B — 나에게 보내기(self chat)**: WhatsApp에서 자기 자신에게 10개 틀을 보내두면,
  발송 시 그 메세지를 복사해 씁니다. (PC에서 문구를 작성해 폰으로 넘길 때도 유용)
- **방법 C — Business 빠른 답장**: 설정 → 비즈니스 도구 → **빠른 답장** 에서
  각 틀을 단축어(예: `/1`, `/생일`)로 등록. **짧은 틀**에 적합(긴 문구는 잘릴 수 있어
  방법 A/B 병행 권장).

## 4. 실제 발송 루틴 (매번)

1. 보낼 틀을 **복사**합니다(삼성 노트/나에게 보내기 등에서).
2. 채팅 목록에서 **브로드캐스트 목록**을 엽니다(제목에 📢 확성기 표시).
3. 입력창에 **붙여넣기** 합니다.
4. **전송(➤)** 을 누릅니다.

→ 목록의 모든 교인에게 **각각 개별 1:1 메세지**로 전달됩니다.

> ⚠️ **정상 동작 안내**: 보낸 메세지는 **내 폰의 각 교인 1:1 대화방에는 나타나지
> 않습니다.** 📢 브로드캐스트 대화방에만 남습니다(교인 폰에서는 각자 1:1로 정상 도착).
> 1:1 방이 비어 보여도 고장이 아닙니다.

---

## 4-1. 잘 보내졌는지 확인하는 법

1. **📢 브로드캐스트 대화방**을 열어 보낸 메세지 옆 **체크표시**를 확인:
   - 🕐 시계 = 전송 중(네트워크 확인) · ✓ = 서버 전송 · ✓✓ 회색 = **상대 폰 도착** ·
     ✓✓ 파랑 = **읽음**
2. 더 정확히: 메세지 **길게 누르기 → ⋮ → 정보(Message info)** → 전달됨/읽음 목록 확인.
3. 가장 확실: **신뢰하는 교인 한 명에게 "받으셨어요?"** 확인.

## 5. 누락자 확인·보완 (번호 미저장자 챙기기)

1. 방금 보낸 브로드캐스트 메세지를 **길게 누릅니다**.
2. **⋮ → 정보(Message info)** 를 엽니다.
3. **전달됨(Delivered)** 목록을 확인합니다.
   - 여기에 **없는** 교인 = 번호를 저장하지 않아 못 받은 사람입니다.
4. 그 **소수만** 골라, 각자의 1:1 대화방에서 같은 문구를 **개별로 복사·전송**합니다.
   (보통 5~15명 수준이라 몇 분이면 끝납니다.)

> 이 정도 소수를 위해 WhatsApp Cloud API로 전환하는 것은 계정 개설·번호 등록·템플릿
> 승인·과금 부담이 커서 **권하지 않습니다.** 수기 발송이 훨씬 간단합니다.

## 6. 폰 vs Windows(데스크톱)

- 브로드캐스트 목록 **만들기는 폰(모바일) 전용**입니다. **Windows 앱 / WhatsApp Web
  에서는 목록을 만들 수 없습니다**(2026년 현재 Meta 미지원).
- 보내기도 **폰에서 하는 게 가장 확실**합니다(폰에서 만든 목록이 데스크톱에 보일 때도
  있으나 버전·상황에 따라 안 보일 수 있어 보장되지 않음).
- **PC로 긴 문구 작성이 편하다면**: PC(WhatsApp Web/Desktop)에서 문구를 작성해
  **"나에게 보내기"** 로 폰에 넘긴 뒤, 폰에서 브로드캐스트 목록에 붙여넣으세요.

## 7. 한계·관리 팁

- **한 목록 최대 256명** → 166명은 1개로 충분. 나중에 256명을 넘으면 목록을 2개로 나눠
  두 번 보내면 됩니다.
- 목록 **인원 추가/삭제**: 목록 열기 → 상단 제목 → 정보 → 수신자 편집.
- **너무 잦은 발송은 자제**하세요. 받는 분들이 부담을 느끼거나 차단하면 이후 전달률이
  떨어질 수 있습니다.
- 답장은 **1:1로만** 목사님께 옵니다(서로 안 보임). 심방·상담용으로도 활용 가능합니다.
