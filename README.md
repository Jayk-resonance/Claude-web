# 마이크로 자산 인수 실사 시스템

Motion Invest 같은 마켓플레이스에 올라온 **소형 온라인 자산**(콘텐츠 사이트·뉴스레터·
디지털 상품 샵)을 검토해 인수 여부를 판단하는 작업 도구입니다. Claude Code 세션 안에서
슬래시 커맨드로 돌아갑니다.

**절대 규칙: S2 검증을 통과하기 전에 환불불가 보증금을 넣지 않는다.**

## 스테이지 게이트

| 단계 | 이름 | 투입 | 산출물 | 목표 통과율 |
|---|---|---|---|---|
| S0 | 스크리닝 | 5분 | `00-screen.md` | ~20% |
| S1 | 정밀 실사 | 1~2시간 | `01-ic-memo.md` | ~40% |
| S2 | 검증 | 대기 | `02-questions.md` → `03-answers.md` | ~50% |
| S3 | 협상 | | `04-decision.md` | |
| S4 | 클로징 | | 자산 이전 체크리스트 | |
| S5 | 밸류업 | 12개월 | 90일 플랜 + 월간 추적 | |

## 커맨드

| 커맨드 | 하는 일 |
|---|---|
| `/screen <번호>` | 매물 스크린샷을 5분 스크리닝해 PASS/HOLD/KILL 판정 |
| `/dd <번호>` | 정밀 실사 IC 메모 작성 후 레드팀 검증 |
| `/ask <번호>` | 셀러·플랫폼 질의 이메일 생성, 답변 도착 시 채점 |
| `/compare` | 전체 매물 순위 재정렬 및 `pipeline.md` 갱신 |

`/screen`은 `deal-screener`, `/dd`의 레드팀 단계는 `deal-skeptic` 서브에이전트가 맡습니다
(`.claude/agents/`).

## 구조

```
DEALS.md            작업 규칙 — 스테이지 게이트, 판정 기준
pipeline.md         매물 파이프라인 현황 + 단계별 통과율 진단
_knowledge/         판단 근거 — 루브릭, 밸류에이션, 레드플래그, 운영난이도, 광고 네트워크 등
_templates/         산출물 양식 — 스크린 카드, IC 메모, 셀러/플랫폼 질의 이메일
NNN-<도메인>/       매물별 검토 기록 (00-screen → 04-decision)
.claude/            스킬·서브에이전트 정의
```

매물은 번호 폴더로 쌓입니다. 예: `001-learnkorean24/`

## 통과율을 읽는 법

단계별 통과율은 **누적 10건 이상부터** 의미가 있습니다. 그 전 숫자는 노이즈입니다.
소량 배치(2~3건)를 볼 때는 배치별 통과율을 보지 말고 누적으로만 보세요 —
**배치 전체가 KILL인 것은 정상적인 결과이며**, 희소성 때문에 기준을 낮추면 안 됩니다
(`_knowledge/screening-rubric.md`의 희소성 하 선택 편향 참고).
