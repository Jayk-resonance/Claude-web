# Claude-web — `/debate` 멀티에이전트 토론 도구

하나의 논쟁적 질문을 **찬성(PRO)·반대(CON)** 양측으로 토론시키고, 중립 심판
**(JUDGE)** 이 균형 잡힌 결론을 내리는 멀티에이전트 토론 도구입니다. 각 역할은 서로
독립된 **서브에이전트**로 실행되어, 한 역할이 다른 역할의 속내를 모르는 상태에서
진짜 토론처럼 쟁점이 맞부딪힙니다.

Claude Code 세션 안에서 동작하므로 **별도 API 키나 추가 요금이 들지 않습니다.**

## 사용법

Claude Code 세션에서 슬래시 명령으로 실행합니다:

```
/debate <찬반으로 갈리는 단일 명제 주제>
```

예시:

```
/debate 중국 배터리 업체가 2026년 현행 미국 FEOC/PFE 규제 하에서 합작·라이선스 구조로 미국 내 ESS를 생산·판매할 수 있는가?
```

주제 없이 `/debate`만 입력하면 주제를 먼저 물어봅니다.

> **좋은 주제 형태:** 찬반이 명확히 갈리는 단일 명제(yes/no). "~ 전망은?", "어느 쪽이
> 유리한가?" 같은 비-찬반/다지선다형은 토론보다 일반 분석에 가깝습니다.

## 진행 방식

다섯 단계를 서브에이전트로 순차 실행합니다. 각 단계는 앞 단계의 발언을 입력으로 받습니다.
각 역할은 `.claude/agents/` 의 **독립 파일로 정의**되어, 모델과 페르소나가 고정되고 서로
격리됩니다.

| 단계 | 역할 | 에이전트 | 모델 | 웹 검색 |
|------|------|----------|------|---------|
| 1 | PRO 입론 | `debate-pro` | Sonnet | ✅ |
| 2 | CON 반박 | `debate-con` | Sonnet | ✅ |
| 3 | PRO 재반박 | `debate-pro` | Sonnet | ✅ |
| 4 | CON 재반박 | `debate-con` | Sonnet | ✅ |
| 5 | JUDGE 종합 | `debate-judge` | Opus | ❌ (평가만) |

- 변론(PRO/CON)은 **웹 검색으로 최신 근거·출처를 확인**하고, 종합(JUDGE)은 검색 없이
  양측을 평가합니다.
- JUDGE는 **발언 순서나 마지막 발언권을 강도로 보지 않고**, 논거의 질과 근거로만
  판단하도록 지시되어 있습니다.
- 결과는 5개 마크다운 섹션(찬성 입론 / 반대 반박 / 찬성 재반박 / 반대 재반박 / 종합 판단)
  으로 정리되어 출력됩니다.

## 구성

```
.claude/
├── agents/
│   ├── debate-pro.md      찬성(PRO) 변론 에이전트   — 모델: Sonnet
│   ├── debate-con.md      반대(CON) 변론 에이전트   — 모델: Sonnet
│   └── debate-judge.md    종합 심판(JUDGE) 에이전트 — 모델: Opus
└── commands/
    └── debate.md          위 세 에이전트를 순서대로 호출하는 /debate 명령
CLAUDE.md                  작업 가이드라인
```
