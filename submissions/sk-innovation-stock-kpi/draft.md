## 사례 개요 초안

SK Inc.는 SK이노베이션, SK텔레콤, SK하이닉스 등 멤버사의 CEO 핵심성과지표(KPI)를 평가합니다. 그중 주가 항목은 여러 멤버사에 공통으로 적용될 수 있는 대표 지표지만, 회사별 주가만 확인해서는 평가할 수 없습니다. SK이노베이션의 경우 자사와 8개 비교회사의 데이터를 같은 기간과 기준으로 정리하고, 상대 성과와 평가 규칙을 차례로 계산해야 합니다. 이 과정은 숫자를 만드는 데서 끝나지 않습니다. 결과가 왜 나왔는지 설명하고, 기준을 바꾸면 점수가 어떻게 달라지는지도 검토해야 합니다.

이를 위해 AI가 매일 시장 데이터를 확인하고 정리하도록 했으며, 점수 계산은 미리 정한 규칙을 담은 프로그램이 맡도록 역할을 나눴습니다. 사용자는 웹 화면에서 현재 평가 결과, 점수를 움직인 원인, 다음 연도 평가 조건별 결과를 이어서 볼 수 있습니다. 현재 공개 화면에는 9개 회사의 11개월 데이터가 누락 없이 연결되어 있습니다. 또 과거 한 시점을 비교하는 과정에서 계산 방식의 작은 차이보다 평가 기간 선택이 점수를 최대 53점 바꿀 수 있다는 사실도 확인했습니다. `[확인 필요: 실제 사용 횟수, 기존 대비 소요시간, 멤버사별 주가 KPI 적용 범위]`

## 1. 배경 및 문제 정의 (Why)

### CEO 평가에서 주가 KPI가 갖는 의미

CEO KPI는 회사의 한 해 성과를 평가하는 기준입니다. SK Inc.는 여러 SK 멤버사의 CEO KPI를 평가하며, 주가는 경영 성과에 대한 시장의 평가를 보여주는 중요한 항목입니다. 따라서 주가 KPI는 단순한 통계 작성이 아니라 CEO 평가의 근거를 만들고 설명하는 업무와 맞닿아 있습니다.

주가 평가는 겉보기보다 복잡합니다. SK이노베이션의 성과만 보는 것이 아니라 8개 비교회사의 성과와 함께 살펴야 하고, 어느 기간의 데이터를 쓸지, 평균을 어떻게 계산할지, 사업군별 비중을 어떻게 반영할지에 따라 결과가 달라집니다. 계산 결과가 맞는 것만큼, 그 숫자가 어떤 자료와 기준에서 나왔는지 설명할 수 있어야 합니다.

### 사람이 직접 처리할 때의 어려움

기존 방식에서는 여러 회사의 데이터를 반복해서 모으고 형식을 맞춘 뒤, 평가 규칙을 적용해 계산해야 합니다. 조건 하나가 바뀌면 같은 작업을 다시 해야 하고, 결과에 대한 질문이 들어오면 원자료와 중간 계산을 거슬러 올라가며 원인을 찾아야 합니다. 다음 연도 KPI를 설계할 때도 여러 조건을 손으로 바꿔 보며 영향을 비교해야 합니다.

이 과정에서 생기는 가장 큰 어려움은 계산량 자체보다 일관성과 설명 가능성입니다. 서로 다른 날짜나 기준이 섞이면 숫자는 나와도 신뢰하기 어렵고, 최종 점수만 남으면 왜 달라졌는지 바로 답하기 어렵습니다. `[확인 필요: 기존 작업 도구, 1회 소요시간, 실제 재작업 또는 질의 대응 사례]`

### 해결 목표

목표는 사람의 판단을 없애는 것이 아니었습니다. AI와 프로그램이 반복 수집과 계산을 맡고, 담당자는 같은 화면에서 결과의 근거를 확인한 뒤 평가 기준과 예외 사항을 판단하도록 하는 것이었습니다. 현재 점수를 보여주는 데서 그치지 않고, 결과의 이유와 다음 연도 기준 변경의 영향까지 이어서 볼 수 있는 평가 지원 도구를 만들고자 했습니다.

## 2. 구현 방법 및 활용 Tool (How / What)

### 어떻게 구현했는가

AI가 SK이노베이션과 8개 비교회사의 일별 주가 데이터를 확인하고 정리합니다. 수집 당시의 원본 데이터는 그대로 보관하고, 점수는 사전에 정한 평가 규칙을 담은 Python 계산 프로그램이 산출합니다. 이후 데이터 누락과 계산 오류를 점검한 결과만 웹 화면에 제공합니다.

역할을 이렇게 나눈 이유는 명확합니다. AI는 반복적인 자료 확인과 개발을 빠르게 돕지만, 중요한 평가 숫자를 임의로 해석해 만들게 하지 않았습니다. 같은 자료와 기준을 넣으면 항상 같은 결과가 나오도록 계산은 프로그램이 맡고, 사람은 평가 규칙과 예외 사항을 최종 판단합니다.

사용자는 한 사이트에서 다음 세 가지 일을 할 수 있습니다.

- **현재 평가 확인:** SK이노베이션의 자체 성과와 비교회사 대비 성과가 점수에 어떻게 반영됐는지 단계별로 확인
- **주가 흐름 점검:** 9개 회사의 현재가와 기간별 추세, 데이터 상태를 한 화면에서 비교
- **다음 연도 기준 설계:** 평가 기간과 계산 조건을 바꿔 보며 기준가격과 예상 점수의 변화를 즉시 비교

### 활용 도구와 역할

| 도구 | 실제 역할 |
|---|---|
| PlayMCP 한국주식정보 | 9개 회사의 일별 주가·거래량·거래대금 확인 |
| Codex 반복 작업 | 정해진 주기에 맞춘 데이터 확인, 오류 점검, 사이트 갱신 지원 |
| Claude | 초기 요구사항 정리, 화면 및 계산 구조 설계, 구현 지원 |
| Python과 pytest | 정해진 평가 규칙에 따른 계산과 결과 검증 |
| GitHub Pages | 별도 설치 없이 볼 수 있는 웹 화면 배포 |

전체 흐름은 `시장 데이터 확인 → 수집 당시 원본 보관 → 평가 규칙에 따른 계산 → 누락·오류 점검 → 웹 화면 제공`으로 구성했습니다.

### 신뢰할 수 있게 만든 장치

- 원본 데이터와 계산 결과를 분리해, 결과에서 사용한 자료까지 다시 확인할 수 있습니다.
- 주요 계산 규칙은 자동 시험을 거쳐 수정 이후에도 같은 방식으로 작동하는지 점검합니다.
- 데이터가 비거나 갑자기 달라지는 경우 경고하고, 확인되지 않은 자료로 화면을 갱신하지 않도록 설계했습니다.
- 공식 기준값과 공개 데이터가 맞지 않는 부분은 숨기지 않고 화면에 알려 담당자가 판단하도록 했습니다.

## 3. 핵심 가치 (Value Proposition)

### 3-1. Biz. Impact

이 도구의 가치는 계산 시간을 줄이는 데만 있지 않습니다. 담당자는 현재 점수, 점수가 달라진 이유, 기준 변경에 따른 결과를 한 화면에서 이어서 확인할 수 있습니다. 질문이 생길 때마다 여러 파일을 다시 찾고 계산하는 대신, 동일한 자료와 규칙을 바탕으로 결과를 설명할 수 있습니다.

현재 공개 근거로 확인할 수 있는 성과는 다음과 같습니다.

- 9개 회사의 11개월 데이터를 하나의 화면에 연결했고, 공개 화면 기준 수집 공백과 누락은 0건입니다.
- 두 가지 평균 계산 방식의 차이는 점수에 1점 미만의 영향을 주는 반면, 평가 기간 선택은 과거 특정 시점의 점수를 최대 53점 바꿀 수 있음을 발견했습니다.
- 이 차이를 다음 연도 KPI 기준을 검토할 때 바로 비교할 수 있도록 만들었습니다.

### 3-2. 확장 가능성

이 사례는 SK이노베이션 한 회사의 주가를 보여주는 사이트로 끝나지 않습니다. SK Inc.가 여러 멤버사의 CEO KPI를 평가하고, 주가 항목이 다수 멤버사에 공통으로 활용된다면 동일한 업무 구조가 반복됩니다. 즉, `평가 대상 회사 + 비교회사 + 평가 기간과 규칙`만 달라지고, 데이터를 모으고 계산하고 검증하며 결과를 설명하는 흐름은 재사용할 수 있습니다.

SK텔레콤, SK하이닉스 등 다른 멤버사에 적용할 때는 대상 회사와 비교회사 목록, 해당 회사의 평가 규칙, 데이터 연결 방식만 정하면 됩니다. 먼저 기존 수기 결과 한 건과 시스템 결과를 대조하고, 차이가 없음을 확인한 뒤 과거 데이터와 정기 운영으로 넓히는 방식이 안전합니다. `[확인 필요: 실제 주가 KPI 적용 멤버사 범위와 공통 산식 여부]`

### 3-3. 혁신성

기존에는 점수를 계산한 뒤 결과를 설명하고, 다음 연도 조건을 검토하는 일이 서로 떨어져 있었습니다. 이 사례는 세 단계를 하나의 흐름으로 연결했습니다. AI는 매일 반복되는 데이터 확인을 돕고, 고정된 프로그램은 평가 숫자의 일관성을 지키며, 사람은 결과의 근거를 보고 기준을 결정합니다.

또한 “어떤 계산식을 쓰느냐”에만 집중하지 않고, 실제 평가 결과를 더 크게 움직이는 조건이 무엇인지 데이터로 비교했습니다. 그 결과 평가 기간 선택이 특정 과거 시점에서 최대 53점의 차이를 만들 수 있음을 확인했고, 단순 계산 도구를 다음 연도 KPI 기준을 검토하는 의사결정 도구로 확장했습니다.
