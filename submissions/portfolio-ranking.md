# 공개 GitHub 작품 잠정 우선순위

아래 평가는 공개 저장소와 실제 배포 화면만 본 1차 판단이다. 공식 세부 가중치는 임의로 만들지 않았고, 실제 활용 성과와 보안·저작권 확인에 따라 순위가 바뀔 수 있다.

## 1순위 — SK이노베이션 CEO 주가 KPI

- GitHub: https://github.com/Jayk-resonance/sk-innovation-stock-kpi
- Demo: https://jayk-resonance.github.io/sk-innovation-stock-kpi/
- 강점: CEO KPI라는 명확한 현업 의사결정, 원자료부터 점수까지의 감사 추적, 9종목·11개월 결측 0건, 산식·기간 민감도 비교, 다음 연도 과제 설계로의 확장
- 승부 포인트: “계산 자동화”보다 “53점까지 흔드는 설계 변수를 발견하고 설명 가능한 운영 체계로 바꿈”
- 필요한 증거: 실제 전후 시간, 활용 횟수, 질의 대응·의사결정 사례, 사용 AI 도구
- 제출 전 위험: CEO KPI 산식·점수·Peer 가중치 등 내부 경영정보 가능성, 공개된 개인 이메일, KIS 시세 재배포 조건, 화면의 `NaN%`, 저장소 라이선스 부재

## 2순위 — SK이노베이션 AI News Brief

- GitHub: https://github.com/Jayk-resonance/SKI-News-Archive
- Demo: https://jayk-resonance.github.io/SKI-News-Archive/
- 강점: 7개 사업부문, 768건 공개 화면, 일일 수집·중복병합·분류·요약·인사이트·배포·이메일의 반복 업무 흐름, 44개 이슈 타임라인과 43개 인사이트로 단발성 요약을 넘어선 조직 지식 축적
- 승부 포인트: “뉴스 요약”이 아니라 `기사 → 이슈 타임라인 → SK 관점 시사점 → 일일/주간 전달`로 이어지는 의사결정 기억 장치
- 필요한 증거: 기존 뉴스 모니터링 시간, 일일 수신자·열람·활용 사례, 누락률·중복 제거율, 실제 AI 도구와 프롬프트
- 제출 전 위험: 기사 저작권·요약 범위, 이메일 수신자 개인정보, 자동 수집 원문과 공개 사이트의 라이선스 점검. 8월 27일 확인 시 최신 브리핑은 8월 21일이므로 운영 공백 원인 확인 필요

## 3순위 — K-배터리 리포트 인텔리전스

- GitHub: https://github.com/Jayk-resonance/K-battery-financials
- Demo: https://jayk-resonance.github.io/K-battery-financials/
- 강점: 163건·27개 증권사·2,342페이지·3.1년을 구조화하고, 전망 분포·과거 추정 오차·이슈별 평가·시장·회사 데이터를 원문 페이지까지 역추적
- 승부 포인트: 생성형 요약을 “원문 MD + 구조화 인덱스”로 분리해 비교·검증·재사용이 가능한 분석 DB로 바꿈
- 필요한 증거: 리포트 1건 처리시간 전후, 분석 요청 대응시간, 실제 보고·의사결정 활용, 정량 추출 정확도
- 제출 전 위험: 공개 저장소에 증권사 리포트 PDF가 다수 있어 재배포 권리 문제가 가장 큼. 권리 확인 전에는 GitHub 링크 제출을 보류하고 정제된 데모만 사용하는 편이 안전
