## 1. 제휴 마케팅 🟢

**원리:** 다른 회사 상품을 추천하고, 내 전용 추적 링크로 구매·가입이 발생하면 수수료.

**절차:** 프로그램 가입(무료, 승인 며칠) → 상위 트래픽 페이지 10~20개 파악 → 맥락에 맞게 링크·박스 삽입(AI 초안 + 검수) → 제휴 링크 고지 문구 추가

**수익 추정 — 두 방법으로 교차검증:**
```
A. RPM 방식: 학습·정보 의도 트래픽이면 1,000PV당 $1~3 (보수적으로 $1)
B. 깔때기: 링크 노출 PV × 클릭률(1.5%) × 전환율(3%) × 건당 수수료
```
두 방법이 수렴하지 않으면 가정을 재검토할 것.

**주의:** 초급·저소득 방문자 비중이 크면 전환율을 낮게 잡을 것. 쿠키 기간은 보통 30일.

## 2. 이메일 + 유료 상품 💰

**두 부분을 분리해서 평가할 것 — 뭉치면 과대평가된다.**

| | 이메일 수집만 | 유료 상품 |
|---|---|---|
| 직접 수익 | **≈ $0** | 되면 유의미 |
| 역할 | 옵션가치(상품의 전제조건) | 실제 수익원 |
| 셋업 | ~15h | 60~100h |
| 성공 확률 | 쉬움 | **불확실 — $0 실패 가능** |

> **이메일 리스트 자체는 돈이 안 된다.** 뭔가를 팔 때만 돈이 된다.

**상품 수익은 확률 가중할 것.** 예: 0.5 × $120 + 0.5 × $30 = 기대값 $75/월.

### ⭐ 핵심: 상품은 "창작"이 아니라 "재포장"이다

기존 콘텐츠 소유권이 매각에 포함되므로, **새 지식을 만들 필요가 없다.**
사람들은 **편의성**에 돈을 낸다 — 흩어진 무료 콘텐츠를 정리된 파일로, 오프라인·인쇄 가능, 광고 없이, 순서대로.

| 상품 | 신규 콘텐츠 필요? | 내 강점 활용 |
|---|---|---|
| 완성본 워크북 PDF | ❌ 재편집만 | 편집 + 정확성 검수 |
| **원어민 오디오팩** | ❌ 읽기만 | ⭐ 한국어 원어민 |
| 인쇄용 치트시트 | ❌ 요약 | 편집 |
| 연습문제집 | ❌ 재구성 | 편집 |

**역할 재정의: "교사"가 아니라 "프로듀서/편집자".** 이 구분이 영어 약점을 우회한다.

**도구 (코딩 불필요):**
- 판매: Gumroad(월 0원, 판매당 10% + $0.50) 또는 Payhip(판매당 5%)
- 이메일: MailerLite(무료 250명/월 2,500발송/자동화 3개) 또는 Beehiiv·EmailOctopus(2,500명 무료)
- 디자인: Canva 템플릿 / 이북 편집은 Fiverr $30~50 외주 가능
- **PPP(구매력 평가) 가격**: Gumroad 기본 지원 — 미국 $19 / 저소득국 $7. 저tier 트래픽을 매출로 전환하는 핵심 장치

⚠️ **기존 무료 콘텐츠를 유료로 막지 말 것.** 무료는 이메일 미끼로 두고, 유료는 **업그레이드판을 신규 제작**.

## 3. 광고 최적화 🟡

**기대치를 낮게 잡을 것.** 대부분의 광고망은 자동 최적화가 이미 돌고 있어서, 매도자가 손 안 대도 어느 정도 최적화된 상태다.

**진단 먼저:** RPM이 낮은 원인이 **배치**인가 **geo**인가?
- geo가 원인이면 → **광고망을 바꿔도 안 오른다.** 기대치 $0에 가깝게
- 미최적화가 원인이면 → RPM +15% 정도

**현실적 기대: +$10~30/월, 또는 0.** 이 레버로 딜을 정당화하지 말 것.

## 4. 콘텐츠 확장 🔴

**주제 선정 (비전문가용 순서):**
1. **이미 되는 걸 키우기** — Search Console에서 **검색 4~10위 키워드**를 찾아 그 글을 보강. 가장 빠른 성과
2. **경쟁 낮은 긴 검색어** 노리기 (짧고 큰 단어는 못 이김)
3. **트렌드** — 화제 작품·시즌 이슈를 기존 주제 안에서

**도구 분담:** 방향(검색량·경쟁도)은 Search Console + 키워드 툴 → 초안·영어는 Claude → **정확성 최종 검수는 내가(원어민 강점)**

**적합도 🔴:** 영어 콘텐츠 대량 생산 = 최대 약점. 시간당 가치가 가장 낮은 레버.
취미로 1~2주 1편은 괜찮지만 **수익 레버로 기대하지 말 것.**

## 5. YouTube 수익화 ⚪

**자격이 관건:** 구독자 1,000명 + **최근 12개월 공개 시청 4,000시간**. 구독자는 통과해도 시청시간에서 막히는 경우가 대부분.

**사전 추정:** 연 조회수 × 평균 시청 길이 ÷ 60 ≈ 연 시청시간. 4,000시간에 한참 못 미치면 자격 없음.

**자격 미달 시:** 영상 15~25편을 새로 만들어야 하고, 그 노동 대비 수익은 시간당 $5~8 수준 → **광고 수익 목적으로는 추진하지 말 것.**

**그럼 유튜브의 가치는?**
1. **신뢰 표식** (구독자 수 = 브랜드 연식 증명)
2. **백카탈로그 유입** — 기존 영상이 검색·추천으로 지금도 사이트에 트래픽 공급
3. **미래 옵션** — 유료 상품 출시 시 잠든 구독자의 2~5%만 깨워도 초기 종잣돈

→ **성장 엔진이 아니라 보너스로 값을 매길 것.** 이것 때문에 매입가에 프리미엄을 주지 말 것.

**신규 영상을 만든다면:**
- **기존 채널 주제 안에서** 트렌드 소재 (생뚱맞으면 알고리즘이 혼란)
- **얼굴 없는 슬라이드형** — Canva + CapCut. 원어민 발음만 쓰고 영어 온카메라는 회피
- 한국어는 반드시 직접 녹음(AI는 한국어 발음이 부정확), 영어는 AI 음성도 무방
- ⚠️ **저작권 있는 영상·스틸 금지.** 자체 그래픽 + 무료 스톡만

## 실행 우선순위 원칙

```
1. 쉬운 레버(제휴 + 광고 + 이메일)로 회수 논리를 세운다
2. 제휴 전환율을 소액 실측한다 ← 모델의 최대 불확실성을 여기서 해소
3. 전환이 확인되면 유료 상품에 투자한다
4. 콘텐츠·유튜브는 옵션으로 둔다
```

**절대 하지 말 것: 상품 대박을 전제로 풀 프라이스 지불.** 그건 인수자의 약점에 베팅하는 것이다.
