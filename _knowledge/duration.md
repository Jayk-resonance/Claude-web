# 존속기간 평가

**이 자산이 몇 년 살까 — 밸류에이션의 가장 근본적인 변수.**

배수는 곧 회수기간이다. 3.3배는 "이게 최소 3.3년은 간다"는 베팅이고,
편안하려면 그보다 훨씬 오래 가야 한다.

---

## 왜 이게 결정적인가

$4,200에 연 $1,262을 사는 경우, **자산 수명만으로 IRR이 뒤집힌다:**

| 자산 수명 | IRR |
|---|---:|
| 3년 | **−6%** (원금도 회수 못 함) |
| 4년 | +8% |
| 5년 | +15% |
| 7년 | +23% |
| 10년 | +28% |
| 영구 | 30% |

> **"연 30% 수익률"은 영구 존속 가정에서만 나온다.**
> 실제로는 **소멸하는 자산(wasting asset)**이며, 시장 배수 2.5~3.5x는
> "이 자산군은 대략 5~7년쯤 간다"는 집단적 추정치다.

---

## 기대 존속기간 산출

**기준 5년에서 가감. 요인당 ±0.5~2년. 상한 10년 / 하한 2년.**

| 요인 | 조정 | 근거 |
|---|---:|---|
| 구글 의존 < 40% | **+1** | 알고리즘 단일 실패점 없음 |
| 구글 의존 40~70% | 0 | |
| 구글 의존 > 80% | **−2** | 코어 업데이트 한 방에 소멸 가능 |
| 다이렉트 유입 30%+ | **+1** | 브랜드 = 알고리즘과 무관하게 지속 |
| 에버그린 콘텐츠 | **+1** | 문법·기초 지식·방법론은 10년 가도 유효 |
| 시의성 콘텐츠 | **−2** | "2026 최고의 X"는 1년이면 죽음 |
| **AI 답변에 취약** | **−2** | 단순 질의응답형 — AI가 클릭을 가로챔 |
| **AI 답변에 저항** | **+1** | 학습 경로·오디오·도구·커뮤니티·다운로드물 |
| 자연 백링크 + 연식 5년+ | **+0.5** | 복제에 시간이 걸림 |
| 니치 성장 중 | **+0.5** | |
| 니치 사양 | **−2** | |
| 무관리 상태에서 유지 실증 | **+0.5** | 자연 감쇠율이 낮다는 증거 |
| 수익화 플랫폼 단일 의존 | **−1** | 자산은 살아도 현금흐름이 먼저 죽음 |

### ⭐ AI 답변 취약도 — 지금 가장 중요한 신규 변수

과거 데이터에 안 잡히고, **이 자산군 전체의 존속기간 가정을 흔들고 있다.**

| 취약 (−2) | 저항 (+1) |
|---|---|
| 단답형 질의 ("X를 한국어로?") | 단계적 학습 경로 |
| 정의·설명 위주 | 오디오·영상 등 텍스트 아닌 자산 |
| 목록·비교표 | 다운로드물(PDF·워크북) |
| 뉴스·요약 | 커뮤니티·상호작용 |
| | 도구·계산기·퀴즈 |
| | 브랜드 충성(다이렉트 유입) |

**판별 질문:** *"이 페이지의 검색어를 AI에 물으면, 사용자가 사이트를 방문할 이유가 남는가?"*

## 안전마진 — 판정 룰

```
안전마진 = 기대 존속기간 ÷ 연배수
```

연배수는 곧 회수기간(년)이므로, 이것은
**"매각이 불가능한 최악의 경우에도 원금을 회수하는가"**를 묻는 하방 테스트다.

| 안전마진 | 판정 | 대응 |
|---|---|---|
| **2.0 이상** | 🟢 양호 | 배수가 정당화됨 |
| 1.5 ~ 2.0 | 🟡 얇음 | 배수를 깎아야 성립 |
| **1.5 미만** | 🔴 **KILL** (K10) | 존속기간이 회수기간을 못 받침 |

**여기서 나오는 실전 룰:**
> **3.3배를 사려면 최소 5년, 편안하려면 7년 존속을 믿어야 한다.**

같은 3.3배라도 구글 의존 85%짜리는 기대 존속 ~4년 → 안전마진 1.2 → **KILL**.
**가격이 같아도 완전히 다른 딜이다.**

## 두 종류의 존속 리스크

매각으로 빠져나갈 계획이라도 리스크는 사라지지 않고 **전가**될 뿐이다.

| | 내용 | 대응 |
|---|---|---|
| **자산 고유 소멸** | 내 사이트가 죽는다 | 위 조정표로 평가 |
| **자산군 재평가** | 내 사이트는 멀쩡한데 **배수 자체가 내려간다** | 통제 불가. AI 답변 확산이 자산군 전체 배수를 압박하는 중 |

두 번째는 특히 주의 — 사는 것도 손해, 파는 것도 손해가 되는 **멀티플 압축** 시나리오다.
그래서 **매각 시점을 길게 잡는 계획일수록 존속기간 평가가 더 중요하다.**

## 추정의 한계 (반드시 병기할 것)

이 조정표는 정밀해 보이지만 **정확하지 않다.** 존속기간은 결국 판단이다.

- 결과는 **±2년 범위**로 표기한다
- 안전마진도 단일 숫자가 아니라 **밴드**로 낸다
- 이 규칙의 진짜 가치는 정확한 숫자가 아니라
  **매물마다 같은 질문을 강제로 묻게 만드는 것**이다
