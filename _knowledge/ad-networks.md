# 광고망 레퍼런스

*최종 확인: 2026-07. 광고망 정책은 자주 바뀌므로 매물 검토 시 재확인할 것.*

## 요건 · 수수료 · RPM 등급

| 광고망 | 진입 요건 | 비용 구조 | 통상 RPM | 이전 마찰 |
|---|---|---|---|---|
| **AdSense** | 없음 | 게시자 68% 수령, 계약 없음 | $1~5 | 🟢 최저 — 내 계정으로 태그 교체 |
| **Ezoic** | 신규 **월 25만 뷰** (2026.2~) | 표준 무료(수익쉐어) / **Premium은 월 $50~500 구독** | $5~15 | 🔴 최고 — 계약 승계·grandfathering |
| **Mediavine Journey** | **월 1,000 세션** | 게시자 75%, 월 정액 없음 | 중상 | 🟡 재심사 + AI 콘텐츠 퇴출 정책 |
| **Mediavine (정식)** | **연 광고수익 $5,000** (또는 월 5만 세션) | 게시자 75%, 정액 없음 | $15~40 | 🟡 재심사 |
| **Raptive** | 월 **25,000 PV** + 10만 PV 미만은 **tier-1 50% 이상** | 게시자 75%, 정액 없음 | $35~47+ | 🟡 재심사 |

> RPM 수치는 퍼블리셔 블로그·광고망 제휴 콘텐츠 출처라 **상방 편향**이 있다.
> **절대값이 아니라 서열로만** 사용할 것. 서열(AdSense < Ezoic < Mediavine < Raptive)은 여러 출처에서 일관됨.

## ⚠️ 벤치마크의 선택 편향 — 반드시 기억할 것

> **"Mediavine RPM $15~40"은 Mediavine이 만든 게 아니라, Mediavine이 그런 사이트만 받아서다.**

문턱이 높은 광고망은 애초에 tier-1 비중 높고 니치 좋은 사이트만 승인한다.
저tier 트래픽 사이트가 Mediavine에 들어간다고 $15가 되지 않는다.

**따라서 광고망 교체 효과를 추정할 때는:**
```
새 광고망 RPM = 현재 관측 RPM × 상대 리프트(1.0~1.4)
```
벤치마크 RPM을 그대로 대입하지 말 것.

## 광고망 교체가 실제로 만드는 차이

**진짜 작동하는 것:**
1. **수요 접근** — 헤더 비딩으로 수십 개 수요처가 동시 입찰 (가장 큰 진짜 요인)
2. **광고 밀도·형태** — 스티키 비디오 등 고단가 지면 추가
3. **프리미엄 광고주 직거래**
4. **최적화 기술** — 배치 실험, 가시성 개선

**착시인 것:**
5. **선택 편향** (위 참조) — 벤치마크 격차의 큰 몫

**현실적 크기:** 같은 사이트를 AdSense → 프리미엄 광고망 = **+30~100%**. 벤치마크의 4~8배가 아님.

**비유:** 광고망은 경매장이다. 좋은 경매장은 입찰자를 더 부르고 물건을 잘 진열해 더 비싸게 판다.
하지만 $100짜리 물건을 $1,000에 팔 수는 없다. **가격대를 정하는 건 물건(= 방문자의 광고 가치)이다.**

## Ezoic 특이사항 (딜 리스크 요인)

- **표준 티어는 무료**(수익쉐어), **Premium만 유료 구독** — $105 버는 사이트에 월 $100 수수료가 붙으면 적자
- **로열티 계약의 전형적 구조: 1년차 수수료 면제 → 이후 부과**
- **자동갱신이 디폴트**이며, 통지 없이 갱신·청구된 사례가 다수 보고됨
- 연약정 중도해지에 **위약금**
- **grandfathered 지위는 "continuous service"에 묶임** → 소유권 이전이 연속성을 깨는지 불명확

**Ezoic 매물 검토 시 반드시 확인 (셀러가 아니라 Ezoic에 직접):**
1. 소유권 이전 후 grandfathered 유지되나
2. 계약 자동갱신 여부·수수료 금액
3. Premium 해지하고 표준(무료)으로 다운그레이드 가능한가
4. 중도해지 위약금

## Mediavine / Journey 특이사항

- 2025년 3월, **"AI 콘텐츠 과다사용"으로 Journey에서 500개 이상 사이트를 사전 경고 없이 퇴출**
- 서드파티 탐지 도구 + **일반인 신고 폼** 양쪽으로 적발
- Journey 요건에 **"frequently updated content"** 명시 → 수년간 신규 발행이 없는 사이트는 승인 리스크
- 콘텐츠가 인간 집필이면 이 리스크에서 자유로움 (역으로, 인수 후 AI 도배는 자산 자살)

## 업계 구조적 역풍 (장기 전망)

광고망들이 동시에 문턱을 올리는 배경:
1. **AI 저품질 콘텐츠 홍수** → 브랜드 안전 문제 → 품질·트래픽 하한 상승
2. **AI 답변이 검색 클릭을 흡수**(제로클릭) → 퍼블리셔 트래픽 총량 감소
3. **서드파티 쿠키 종료** → 1st-party 데이터 인프라 투자 → 대형 퍼블리셔 유리
4. **단위경제** → 엔터프라이즈·고트래픽 중심으로 이동

**결론: 소형 광고기반 콘텐츠 사이트에 장기 역풍. 광고 수익 성장을 가정한 밸류에이션은 금지.**
반대로 이 역풍이 grandfathered 지위의 희소가치를 만들기도 한다.
