# S0 스크리닝 루브릭

목적: **5분 안에 80%를 죽인다.** 살아남은 것만 IC 메모(S1)로 보낸다.

---

## 1단계: 자동 KILL 조건

하나라도 해당하면 **점수 계산 없이 즉시 탈락**. 사유를 명시할 것.

| # | 조건 | 이유 |
|---|---|---|
| K1 | AI 콘텐츠 비중 높음 (Originality human < 80%) | 광고망 퇴출 + SEO + 매각가 3중 리스크 |
| K2 | 구글 검색 트래픽 의존 > 80% | 코어 업데이트 한 번에 자산 증발 |
| K3 | 만료 도메인 매입 / PBN / 301 리다이렉트 사용 | 숨은 패널티 리스크 |
| K4 | 수익 이력 6개월 미만 | 정상 수익력 검증 불가 |
| K5 | 12개월 수익·트래픽이 뚜렷한 하락 추세 | 도피 매각 가능성 |
| K6 | GA / 정산 원본 접근 거부 | 검증 거부는 그 자체로 신호 |
| K7 | 재고·공급처 이전이 필요한 이커머스 | 첫 딜 기준 리스크 과다 |
| K8 | 유지보수가 필요한 SaaS / 앱 / **커스텀 코드 기반 사이트** | 비개발자 부적합 (my-profile 약점) |
| K9 | SK 계열·경쟁사·거래처 관련 자산 | 이해상충 |
| K10 | **안전마진 < 1.5** (기대 존속기간 ÷ 연배수) | 존속기간이 회수기간을 못 받침 → `duration.md` |

> K5 판정 주의: **수익 하락과 트래픽 하락을 구분**할 것. 트래픽은 안정인데 수익만 하락 = RPM 문제(수익화 여지)이지 자산 붕괴가 아니다.

## 2단계: 배점 (100점)

| 항목 | 배점 | 판정 기준 |
|---|---:|---|
| **Tier-1 트래픽 비중** | 25 | 50%+ = 25 / 30~50% = 15 / 15~30% = 8 / 15% 미만 = 3 |
| **밸류업 적합도** | 10 | 내 강점이 남들 못 하는 밸류업을 만드나 (한국 관련=최상) |
| **운영 가능성** | 5 | 비개발자가 굴릴 수 있나 → `operability.md` 판정 가이드 |
| **트래픽 소스 분산** | 15 | 구글 50% 미만 = 15 / 50~70% = 10 / 70~80% = 5 |
| **저수익화 여지** | 15 | 현재 RPM·수익원 수. 제휴·상품 greenfield면 만점 |
| **콘텐츠 진정성 · SEO 해자** | 15 | 인간 집필, 자연 백링크, 상위 랭킹 키워드 수, 사이트 나이 |
| **수익 안정성** | 10 | 12개월 변동폭. 반토막 이력 있으면 감점 |
| **가격 매력도** | 5 | 연순익 대비 배수 (2.5x 이하=5 / 3.0x=3 / 3.5x 이상=1) |

**Tier-1 정의:** 미국·영국·캐나다·호주·뉴질랜드.
⚠️ **전체 세션 대비**로 계산할 것 — GA 표의 "상위 10개국 내 비중"을 그대로 쓰면 과대평가된다.

## 파생 지표 계산식

```
RPM         = 월수익 ÷ (월 페이지뷰 ÷ 1000)
실질 순이익 = 월 매출 − 월 고정비(호스팅·라이선스·도구)
연배수      = 매도가 ÷ (실질 순이익 × 12)
회수기간    = 매도가 ÷ 실질 순이익  (개월)
Tier-1 %    = (US+UK+CA+AU+NZ 세션) ÷ 전체 세션
안전마진    = 기대 존속기간(년) ÷ 연배수      ← duration.md
```

⚠️ **월 고정비를 확인하기 전의 배수는 잠정치다.** 표기 수익이 고정비 차감 전이면 실제 배수는 더 높다.
미확인이면 "미확인(잠정 배수)"으로 표기하고 S1에서 규명한다.

**RPM 해석:**
- $2 이하 → 저tier geo(구조적 한계) 또는 미최적화. geo 분포로 판별
- $5~15 → 정상 범위 (교육·일반 니치)
- $15+ → 고tier geo 또는 고단가 니치

## 스크리닝 시 반드시 확인할 것

- 리스팅이 **"최근 N개월"** 수익만 표기하면 → 12개월 이력을 별도로 찾을 것
- **월 페이지뷰**와 **월 세션**을 혼동하지 말 것 (광고망 요건은 서로 다른 단위를 씀)
- **월 고정비와 기술 스택**은 스크린샷에 없는 경우가 많다 → 미확인으로 기록하고 S1 질의 항목에 올릴 것
- 스크린샷에 없는 항목은 **추정하지 말고 "미확인"으로 기록**
