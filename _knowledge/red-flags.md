## 리스팅 읽는 법 (매도자의 프레이밍)

| 신호 | 실제 의미 | 대응 |
|---|---|---|
| 수익을 **"최근 2개월"** 등 짧은 기간으로 표기 | 회복 국면만 부각. 12개월 평균은 낮을 수 있음 | 재무 섹션에서 12개월 이력 직접 확인 |
| 매도자가 리스크를 **친절히 "고지"** | 정직한 고지일 수도, **책임 전가**일 수도 | 어느 쪽이든 **협상 카드**로 사용 |
| "opportunity to expand into other monetization" | = 현재 **저수익화 상태** | 업사이드이자, 매도자가 안 한 이유를 물을 것 |
| 강세 국면(수익 회복 + 트래픽 상승)에 매도 | **로컬 고점 매도** 가능성 | 회복의 지속성을 별도 검증 |

## 데이터 함정

| 함정 | 설명 |
|---|---|
| **GA 국가별 표가 "상위 10개국 내 비중"** | 합계가 전체 세션보다 작으면 그 %는 부분집합 기준. tier-1 비중이 과대평가됨 → **전체 세션 대비로 재계산** |
| **페이지뷰 vs 세션 혼동** | 광고망 요건은 서로 다른 단위를 씀 (Journey=세션, Raptive=PV, Ezoic=유저) |
| **이탈률 0.5% / 체류 4분+ 같은 비현실적 수치** | GA 트래킹 오설정 의심 → PV 숫자 자체가 부풀려졌을 수 있음 |
| **트래픽은 안정인데 수익만 반토막** | 자산 붕괴가 아니라 **RPM 문제** = 광고망·단가 이슈. 원인 규명 전엔 정상 수익력 신뢰 불가 |

## 플랫폼별 리스크

**Ezoic**
- grandfathered 지위 승계 여부 (셀러 말이 아니라 **Ezoic 서면 확인**)
- Premium 계약 자동갱신 → 월 $100+ 수수료 → 저수익 자산은 적자 전환
- 계약 만료일이 클로징 직후면 특히 위험

**Mediavine Journey**
- AI 콘텐츠 퇴출 정책 (사전 경고 없이 즉시 종료 사례)
- "frequently updated" 요건 → 수년간 발행 0인 사이트는 승인 리스크

**YouTube (딸려오는 채널)**
- **브랜드 계정 여부** — 아니면 소유권 정식 이전 불가
- **YPP 자격**: 최근 12개월 공개 시청 4,000시간 (구독자 수와 별개)
- 최종 업로드가 오래됐으면 구독자는 "잠든 구독자" — 성장 엔진으로 계상하지 말 것
- 조회수 ÷ 영상 길이로 시청시간을 대략 추정해 자격 여부를 사전 판단

**Amazon Associates**
- 수수료율 일방 인하 전력 → 단일 제휴사 집중 리스크
- (단, 제휴 수익 자체는 **구매 의도 트래픽**이라는 좋은 신호)

## 자산 이전 리스크 (되찾기 방지)

> 매도자가 만들고 인증한 자산은 **대충 넘겨받으면 실제로 되찾을 수 있다.**

지배권의 뿌리를 옮기고 잔여 접근을 끊어야 한다:

| 자산 | 올바른 이전 | 잘못된 이전 |
|---|---|---|
| 도메인 | **내 명의 등록기관 계정으로 이전(transfer/push)** | 셀러 계정에 남긴 채 연결만 변경 |
| 호스팅·CMS | 내 계정 + 셀러 관리자 계정 삭제 | 셀러가 관리자로 잔류 |
| YouTube | **브랜드 계정 → 기본 소유자 승격 → 셀러 제거** | 개인 구글 계정 ID/PW만 전달 (복구로 탈취 가능) |
| 모든 계정 | 비밀번호 + **복구 이메일·전화 + 2FA를 내 것으로 교체** | 비밀번호만 변경 |

**3중 안전장치:** 에스크로 / 14~30일 인수인계 기간 / 매매계약서 진술·보증 조항.
Motion Invest 같은 중개 플랫폼은 이 절차를 표준화해 제공한다 → **첫 딜은 개인거래 대신 플랫폼 경유.**

## 매도 사유 판정

**양성(benign) — 대부분 이 경우:**
- 기회비용·번아웃 (6년간 무료 자료 만들어 월 $105면 시급이 최저임금 이하)
- 일시금 > 수년치 수익 (본인이 수익화에 투자 안 할 거라면 합리적)
- 수익화 스킬·흥미 없음 (가르치는 것과 파는 것은 다른 직업)

**악성(malign) — 반드시 배제:**
- 다가오는 하락(알고리즘·정책·트래픽 붕괴)을 알고 도피

**판별법:** 트래픽 추세 / 구글 의존도 / 콘텐츠 진정성 / 최근 알고리즘·정책 변화 이력.
셋 다 깨끗하면 악성 가능성 낮음.

## Key-person 리스크

콘텐츠를 만든 사람(들)이 매각과 함께 떠나고 승계되지 않는 경우.
- **완화 요인**: 콘텐츠가 이미 완성돼 있고 에버그린인가 / 신규 발행 없이도 트래픽이 유지됐는가
- **전제**: 밸류업 계획의 90%를 **"신규 콘텐츠 생산"이 아니라 "기존 트래픽 수익화"**에 실을 것

## 인수 후 자해 행위 (하지 말 것)

- **AI로 콘텐츠 도배** → 광고망 퇴출 + SEO 추락 + 매각가 하락 3중 훼손. AI는 초안·보조 + 사람 검수로만
- **기존 무료 콘텐츠를 유료로 전환** → 트래픽·SEO·신뢰 훼손. 무료는 미끼로 두고 **유료는 업그레이드판을 신규 제작**
- **저작권 있는 이미지·영상 사용**(K-드라마 스틸 포함) → 스틸 한 장도 침해. 채널 삭제 리스크
- **채널 주제와 무관한 콘텐츠 발행** → 알고리즘이 학습한 정체성이 흐려져 노출 하락
