# 운영 가능성 (비개발자 기준)

**"이 자산이 값어치가 있나"와 "내가 이걸 굴릴 수 있나"는 다른 질문이다.**

이 실패 모드는 인수 **후에** 드러나고, 그때는 이미 돈을 냈다.
`my-profile.md`의 "비개발자 / 주 10시간" 제약은 구조적 조건이므로 매물마다 반드시 확인한다.

---

## 1. 기술 스택 — 비개발자 난이도

| 스택 | 난이도 | 설명 |
|---|---|---|
| **WordPress** | 🟢 관리 가능 | 글쓰기·플러그인 설치·테마 변경이 GUI. 문제 생기면 검색하면 답이 나옴. **압도적 다수의 콘텐츠 사이트** |
| Shopify · Ghost · Squarespace 등 SaaS형 | 🟢 관리 가능 | 플랫폼이 유지보수를 대신함. 단 월 구독료 발생 |
| **정적 사이트 생성기** (Hugo·Jekyll·Astro) | 🟡 제한적 | 글 발행에 마크다운·Git·빌드 과정 필요. 배울 수는 있으나 초기 마찰 큼 |
| **커스텀 코드** (React·Next.js·Laravel 등) | 🔴 **불가** | 버그 하나에 손도 못 댐. 개발자 상시 필요 → 사실상 KILL |

**확인 방법:** 브라우저에서 사이트 우클릭 → "페이지 소스 보기" → `wp-content` 문자열이 있으면 WordPress.
또는 매도자에게 직접 질의.

## 2. 커스텀 기능 — 숨은 지뢰

WordPress라도 **특정 기능이 자체 개발 코드**면 그 부분은 유지보수 불가다.

| 기능 | 확인 사항 |
|---|---|
| 퀴즈·테스트 | 시판 플러그인인가, 자체 개발인가 |
| 회원·로그인 | 자체 개발이면 보안 책임까지 따라옴 |
| 계산기·변환기 등 도구 | 커스텀 JS면 고장 시 대응 불가 |
| 결제·구독 | 시판 솔루션(WooCommerce 등)인가 |

**원칙: 트래픽 상위 페이지가 커스텀 기능에 의존하면 위험도가 급상승한다.**
그 기능이 고장나면 트래픽이 통째로 사라진다.

## 3. 월 고정비 — 밸류에이션 오류의 원천

⚠️ **"비용은 호스팅과 도메인뿐"이라는 답변으로 넘어가지 말 것. 금액을 물어야 한다.**

| 항목 | 통상 범위 (월) |
|---|---|
| 호스팅 (공유형) | $5~30 |
| 호스팅 (관리형 WP) | $20~100 |
| 도메인 | ~$1 (연 $10~15) |
| 유료 테마·플러그인 라이선스 | $0~30 |
| 이메일 도구 | $0~50 (구독자 수에 따라) |
| CDN·보안 | $0~20 |

**계산에 반드시 반영:**
```
실질 순이익 = 월 매출 − 월 고정비
연배수 = 매도가 ÷ (실질 순이익 × 12)
```
월 $105 자산에 고정비 $30이면 **순이익의 29%**가 사라진다. 배수가 3.3x → 4.6x로 뛴다.

**질의 시 반드시 확인:** 표기된 월수익이 **고정비 차감 전인가 후인가.**

## 4. 사이트 이전 (마이그레이션)

**"소유권 이전"과 "사이트 이전"은 다르다.**
호스팅이 셀러 계정이면, 내 호스팅으로 사이트를 옮겨야 한다 — 비개발자에겐 진짜 작업이다.

| 시나리오 | 난이도 | 비용 |
|---|---|---|
| 호스팅 계정째 승계 | 🟢 쉬움 | $0 |
| 셀러가 마이그레이션 지원 | 🟢 쉬움 | $0 (계약에 명시할 것) |
| 호스팅사가 무료 마이그레이션 제공 | 🟢 쉬움 | $0 (대형 호스팅은 대부분 제공) |
| 직접 이전 | 🔴 어려움 | 실수 시 사이트 다운 |
| 외주 | 🟡 | **$200~500** |

**협상 포인트:** 마이그레이션 지원을 **인수인계 조항에 명문화**하면 비용과 리스크를 동시에 없앨 수 있다.

## 5. 유료 라이선스 승계

유료 테마·플러그인은 **라이선스가 계정에 묶여 있어** 자동 승계되지 않는 경우가 많다.

승계 안 되면:
- 업데이트 중단 → **보안 취약점 방치** → 해킹 리스크
- 재구매 필요 (연 $50~200)

**질의 항목:** 유료 테마·플러그인 목록과 각각의 라이선스 승계 가능 여부.

## 6. 유지보수 부담 (연간)

| 작업 | 빈도 | 비개발자 난이도 |
|---|---|---|
| 플러그인·테마 업데이트 | 월 1~2회 | 🟢 클릭 몇 번 (단 업데이트 후 사이트 확인 필요) |
| WordPress 코어 업데이트 | 분기 | 🟢 |
| PHP 버전 업그레이드 | 1~2년 | 🟡 호환성 깨질 수 있음 → 호스팅 지원 필요 |
| 백업 | 상시 | 🟢 플러그인·호스팅 자동화 |
| 보안 사고 대응 | 드묾 | 🔴 외주 필요 |

**핵심 완충책: 관리형 호스팅.** 월 $20~40으로 업데이트·백업·보안을 대신해준다.
비개발자에겐 **비용이 아니라 보험**이다. 저가 호스팅을 쓰는 매물이라면 이 비용을 인수 후 예산에 반영할 것.

## 7. 장애 대응 능력

**질문: 사이트가 지금 다운되면 나는 무엇을 할 수 있나?**

| 대응 수단 | 확보 여부 확인 |
|---|---|
| 호스팅 지원 채널 | 24/7 채팅? 이메일만? 응답 시간? |
| 자동 백업 + 원클릭 복구 | 있는가 |
| 스테이징 환경 | 업데이트를 미리 시험할 수 있나 |
| 외주 개발자 | 급할 때 부를 사람이 있나 (없으면 Fiverr·크몽 사전 물색) |

## 8. 페이지 속도 · Core Web Vitals

광고를 붙이거나 플러그인을 추가하면 사이트가 느려지고, **속도 저하는 SEO 순위와 광고 수익을 동시에 깎는다.**

- 인수 전 PageSpeed Insights로 현재 점수를 확인
- 이미 느린 사이트는 밸류업 여지가 좁다 (광고를 더 못 붙임)

## 9. 법적 · 세무 (상품 판매 시)

- 자체 상품 판매 → **사업자등록·세금** 이슈
- 재직 회사 **겸업 규정**과 직결 (`my-profile.md` 참조)
- Gumroad 등 플랫폼이 일부 세금 처리를 대행하나, 국내 소득 신고는 별개

**S1 단계에서 "상품 판매까지 갈 계획이면 겸업 규정을 먼저 확인"이라는 조건을 명시할 것.**
